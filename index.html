08 — Architecture

How it runs at near-zero cost.

Every project I ship sits on the same lean spine. Pick a layer to see what it does and what it actually costs me each month.

Layer 01 · Delivery

Edge & CDN

Every request lands on a global edge network before it touches a server. HTML, CSS, JavaScript and images are cached in hundreds of locations, so a buyer in Toronto and a buyer in Dubai both get a sub-second first paint.

  • Automatic HTTPS and HTTP/3
  • Global caching with instant invalidation
  • DDoS protection and WAF rules
  • Custom domains with zero server config
This layer costs₹0 / month
Layer 02 · Interface

Frontend build

React or Next.js compiled down to static HTML, CSS and JS at build time. No runtime rendering bill and no cold start on the first byte — just files sitting on a CDN, ready to be served.

  • Pre-rendered pages that search engines can index
  • A design system built once and reused everywhere
  • Core Web Vitals treated as a requirement, not a bonus
  • A preview deploy for every single change
This layer costs₹0 / month
Layer 03 · Serverless

API & business logic

Business rules live in small serverless handlers or a single Django service — whichever the workload actually needs. Nothing sits idle waiting for traffic, so nothing bills you while you sleep.

  • Django REST where the work is deeply relational
  • Serverless handlers for webhooks and glue
  • Stateless, so it scales horizontally without drama
  • Secrets held outside the codebase, always
This layer costs₹0–500 / month
Layer 04 · Data

Database

PostgreSQL with real relational integrity — foreign keys, transactions, indexes. The managed free tier comfortably covers the first tens of thousands of records, and scaling past that is a configuration change, not a rewrite.

  • Managed backups and point-in-time recovery
  • Row-level security to isolate multi-tenant data
  • Indexes designed from real query patterns
  • Migrations versioned alongside the code
This layer costs₹0 / month
Layer 05 · Storage

Files & media

Product photos, invoices, PDFs and uploads go straight into object storage and come back out through the CDN. Application servers never handle a file transfer, which keeps them small and cheap.

  • Direct-to-storage uploads, so no server bottleneck
  • Signed URLs protecting private documents
  • Automatic image resizing on delivery
  • Lifecycle rules that archive old files for you
This layer costs₹0 / month
Layer 06 · Jobs

Automation

The unglamorous work that saves the most time: nightly reports, invoice generation, stock syncs and WhatsApp notifications — all triggered on a schedule or by a webhook, never by a person remembering.

  • Scheduled reports emailed to the team
  • Automated invoicing and reconciliations
  • WhatsApp and email notification flows
  • Retries and failure alerts built in from day one
This layer costs₹0 / month
Layer 07 · Observability

Monitoring

If an endpoint slows down or a payment webhook stops firing, I want to know before the client does. Uptime checks, error tracking and one quiet alert channel cover it — no dashboards nobody reads.

  • Uptime checks on the paths that matter
  • Error tracking with real stack traces
  • Alerts pushed to email and WhatsApp
  • A weekly digest instead of a flood of noise
This layer costs₹0 / month
